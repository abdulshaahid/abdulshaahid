# Custom Fonts Directory

Place your Cooper BT font files here. The CSS is configured to automatically load any of the following filenames:

- `CooperBT-MediumItalic.woff2` / `.woff` / `.ttf`
- `cooper-bt-medium-italic.ttf`
- `CooperBT-MdIt.woff2` / `.ttf`

Once placed in `public/fonts/`, it will be served automatically for the "Hey, there" heading on the Hero section.
